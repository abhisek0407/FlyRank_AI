## Target classification

### Target
Books to Scrape

### Why this target?
Books to Scrape is a public sandbox specifically designed for practicing
web scraping.

### Scope
This project will scrape only the first three catalogue pages, containing
60 books.

### Data collected
For each book, the scraper will eventually collect:
- Title
- Product URL
- Price
- Availability
- Rating
- Description
- Source catalogue page
- Fetch timestamp

### Scraping policy
I will not reuse this code on another site without checking its rules
and terms first.
